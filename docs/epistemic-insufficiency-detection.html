When AI Should Say: I Don’t Know Enough Yet

Epistemic Insufficiency Detection · Rakesh Rajan

All papersFull paper on GitHub

Abstract

Agentic systems can fail before uncertainty estimation even begins: they may not recognize that the information available is insufficient to justify choosing an interpretation or state model.

Core proposition

Before asking whether an agent is right, ask whether it had enough information to be right at all.

The risk chain is: missing context → prior substitution → premature commitment → wrong state → wrong action.
