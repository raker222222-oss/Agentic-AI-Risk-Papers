The Annotation Tax

Relational Topology Loss in Human–LLM Conversation · Rakesh Rajan

All papersFull paper on GitHub

Abstract

Large language models can preserve propositional content while altering the relations that determine what those propositions mean. An intuition can become a fact, a conditional response an unconditional intention, a quotation a speaker belief, or a qualifier can lose its scope.

This paper proposes Relational Topology Loss (RTL) as an edge-level framework for studying these failures and the Annotation Tax as the extra communicative work humans must supply to prevent or repair them.

Core proposition

Remembering the proposition is not the same as preserving its relations.

The paper proposes human baselines, neutral-fact controls, relation-perturbation tests, delayed multi-turn probing, and a measurable Excess Annotation Tax.

Agentic implication

An agent need not hallucinate a new instruction. It may only need to lose the relation that made the instruction safe—for example, the loss of an if.

correct utterance → relational corruption → wrong conversational state → coherent reasoning → wrong action
