Agentic State-Model Divergence · Rakesh Rajan

All papersFull paper on GitHub

Abstract

Agentic State-Model Divergence (ASMD) describes failures in which an AI acts competently on an internally coherent but materially wrong representation of the task, authority structure, evidence state, or environment.

Core proposition

An agent does not need the wrong goal to do the wrong thing. It may only need the wrong state.

The central chain is: state-model divergence → competent action → environmental change → feedback → possible reinforcement.
