Independent working papers

Agentic AI Risk Papers

Rakesh Rajan (Rakesh OSS)

Research on how advanced AI agents can fail through bad retrieval, wrong interpretation, incorrect sequencing, distorted evidence thresholds, recursive reasoning, and human-directed misuse—without requiring independent machine will.

Zenodo DOIGitHub repository

Papers

AI-Mediated Interpretive Displacement

How AI-generated interpretations can become hidden causal participants in human communication, changing later behavior and creating apparent confirmation of an initially wrong reading.

Recursive Amplification of Interpretive Failure in Agentic AI

How an initial interpretive error can alter the environment, generate self-produced corroboration, and increase confidence in a mistaken state model.

Sequence Integrity as an Agentic AI Safety Problem

Why correct facts in the wrong order can still create the wrong world state, with implications for temporal reasoning, revision history, precedence, and tool-using agents.

Evidentiary Threshold Distortion in Agentic AI

Why demanding explicit proof can cause dangerous underreaction when convergent evidence is already operationally sufficient.

Open-World Retrieval Failure in Agentic AI

How novel states create knowledge deficits, retrieval-policy gaps, false epistemic closure, source-selection recursion, and Black Swan conditions for autonomous agents.

Rogue Without Will

Separates unintended agentic failure, deliberate human misuse, and independent machine volition, arguing that dangerous outcomes do not require a machine to possess human-like will.

Core proposition

bad retrieval → wrong interpretation → incorrect state model → flawed evidence assessment → locally coherent but externally wrong action

A separate misuse pathway is:

human intent + frontier AI capability + tools + automation + access → disproportionate operational power
