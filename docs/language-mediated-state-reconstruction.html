AI Reconstructs Reality From Language—and Can Reconstruct It Wrong

Language-Mediated State Reconstruction · Rakesh Rajan

All papersFull paper on GitHub

Abstract

Human communication compresses rich world state into language. Language models often face the reverse task: reconstructing the state that could have produced the text. Because this inverse problem is underdetermined, learned priors participate directly in state construction.

Core proposition

Probable reconstruction is not necessarily epistemically warranted reconstruction.

The proposed chain is: lossy linguistic representation → underdetermined state reconstruction → prior-driven selection → coherence preservation → epistemic relation distortion → wrong operative state → agentic feedback.
