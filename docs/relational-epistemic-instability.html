AI Can Remember the Facts and Still Change What They Mean

Relational Epistemic Instability · Rakesh Rajan

All papersFull paper on GitHub

Abstract

Relational Epistemic Instability (REI) describes a higher-order failure in which an AI retains substantially the same information while changing the epistemic relationships among it as framing, salience, or context changes.

Coherence-Dominant Epistemic Reconstruction (CDER) is proposed as one generative mechanism: evidence is reweighted, anomalies downgraded, inferences hardened, or authority and sequence weakened without new evidence.

Core proposition

Memory fidelity is not epistemic fidelity.

Epistemic status must travel with the proposition.
